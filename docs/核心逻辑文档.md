### 3.2 核心匹配算法

**实现函数**: `ImageTag.get_images_by_tags()` - `scripts/iib/db/datamodel.py`

#### SQL查询构建：
```sql
SELECT image.id, image.path, image.size, image.date
FROM image
INNER JOIN image_tag ON image.id = image_tag.image_id
WHERE [动态条件组合]
GROUP BY image.id
[HAVING 子句]
ORDER BY [排序方式]
LIMIT ?
```

### 3.3 三种匹配逻辑详解

#### 3.3.1 完全匹配 (`and_tags`)
**逻辑**: 图片必须同时包含所有指定标签

**SQL实现**:
```sql
-- WHERE条件
tag_id IN (?,?,?)  -- 包含任一指定标签的图片

-- HAVING条件  
GROUP BY image.id
HAVING COUNT(DISTINCT tag_id) = ?  -- 标签数量必须等于and_tags长度
```

**示例**:
```python
and_tags = [1, 5, 10]  # 标签ID: 1=anime, 5=1girl, 10=school_uniform
# 结果：只返回同时包含 anime + 1girl + school_uniform 的图片
```

#### 3.3.2 任意匹配 (`or_tags`)  
**逻辑**: 图片只需包含任一指定标签

**SQL实现**:
```sql
(image_id IN (
  SELECT image_id
  FROM image_tag
  WHERE tag_id IN (?,?,?)  -- 所有or_tags的ID
  GROUP BY image_id
  HAVING COUNT(DISTINCT tag_id) >= 1
))
```

**示例**:
```python  
or_tags = [2, 7, 15]  # 标签ID: 2=blonde, 7=brunette, 15=redhead
# 结果：返回包含 blonde 或 brunette 或 redhead 任一标签的图片
```

#### 3.3.3 排除匹配 (`not_tags`)
**逻辑**: 图片不能包含任何指定标签

**SQL实现**:
```sql
(image_id NOT IN (
  SELECT image_id  
  FROM image_tag
  WHERE tag_id IN (?,?,?)  -- 所有not_tags的ID
))
```

**示例**:
```python
not_tags = [20, 25]  # 标签ID: 20=lowres, 25=bad_anatomy  
# 结果：排除包含 lowres 或 bad_anatomy 的图片
```

### 3.4 组合匹配逻辑

三种条件可以同时使用，通过AND连接：
```sql
WHERE (and_tags条件) AND (or_tags条件) AND (not_tags条件)
```

**复杂查询示例**:
```python
{
    "and_tags": [1, 5],      # 必须包含: anime + 1girl
    "or_tags": [10, 11, 12], # 任选其一: school_uniform OR maid OR nurse  
    "not_tags": [20, 21]     # 排除: lowres + bad_anatomy
}
# 结果：anime风格的1girl角色，穿school_uniform/maid/nurse任一服装，但排除低质量图片
```


```python
def safe_batch_remove(cls, conn: Connection, image_ids: List[int]) -> None:
    if not image_ids:
        return
    
    # 删除图片标签关联
    placeholders = ",".join("?" * len(image_ids))
    cur.execute(f"DELETE FROM image_tag WHERE image_id IN ({placeholders})", image_ids)
    
    # 删除图片记录
    cur.execute(f"DELETE FROM image WHERE id IN ({placeholders})", image_ids)
    
    conn.commit()
```
